## 1. Почему на DELETE возвращается 204, а не 200?

После удаления возвращать нечего. 204 значит всё ок но тела нет

## 2. Что будет с данными при перезапуске сервера?

Они пропадут. Массив лежит в памяти, а при остановке сервера память очищается.
После запуска `seed()` снова создаёт 8 записей. Базы или файла нет, поэтому
сохранять некуда

## 3. Зачем нужен next(err) и что будет, если его убрать?

Он отправляет ошибку в `errorHandler`, а тот отвечает клиенту. Если убрать,
ответа не будет, и запрос повиснет

## 4. Как реализовано правило варианта?

Нельзя добавить занятие, если оно пересекается по времени с другим в тот же
день. Код в `src/services/lessonService.js`:

```js
function checkOverlap(lesson, ignoreId) {
  for (let i = 0; i < lessons.length; i++) {
    const other = lessons[i];
    if (other.id === ignoreId) continue;
    if (other.weekday !== lesson.weekday) continue;
    if (lesson.startTime < other.endTime && lesson.endTime > other.startTime) {
      throw makeErr('Занятие пересекается с "' + other.title + '" (' + other.startTime + '-' + other.endTime + ')', 400);
    }
  }
}
```

Функция проверяет все занятия. Если день другой, пропускает. Если день тот же и
время пересекается, выдаёт ошибку 400

## 5. Где приложение может упасть?

1) если id не найден ошибка 404
2) неверные данные в теле запроса
3) занятия пересекаются
4) сломанный JSON. отвечает 400
5) пустое тело запроса
6) неизвестный адрес
7) любая другая ошибка. ответ 500
